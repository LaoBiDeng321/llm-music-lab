# 外部调研笔记（只读资料）

写这首曲子前做的一轮外部调研结论摘要。**本文件只作参考，不参与构建**；与实际冲突时以代码与乐谱为准。
（检索来源：orphiq.com 悲伤和弦进行、guitarwiz.app 小调和弦、taube.web.illinois.edu 旋律写作规则、Sweetwater 配器 EQ 速查、iZotope 混音指南、forasoft LUFS 目标、Spotify 响度标准化、audiofader 鼓合成。）

## 1 作曲原则

1. 动机先行：2 小节、4–7 个音，全曲只有一个核心动机。
2. 70/30：每 8 小节 70% 重复 + 30% 变形；变形四手段（移位 / 倒影 / 逆行 / 节奏加倍减半）每次只改一项。
3. 强拍（第 1、3 拍）必须落根/三/五音；经过音只放弱拍且 ≤1 拍。
4. 音域分区：sub 41–65 Hz、和声 130–500 Hz、旋律 440–1200 Hz、空气 >6 kHz；同区不叠两个主奏。
5. 拱形轮廓：全曲最高音只出现 1–2 次，落在 65%–75% 处。
6. 留白：每 8 小节至少 1 小节无旋律；段落交界留 0.5–1 小节。
7. 动态弧单峰：1 → 3 → 5 → 7 → 9 → 回落。
8. 同一时刻只有一条最快节奏线。
9. 120 Hz 以下同时只有一个音源（sub 或 kick）。
10. 高潮靠配器层数（2→4→6 层）而不是推音量。
11. 结构模板：Intro 8 / A 16 / B 16 / Climax 16 / Outro 8–12 小节。

## 2 常用和弦进行（A 小调）

| 级数 | 具体和弦 | 色彩 |
|---|---|---|
| i–VI–III–VII | Am–F–C–G | 通用抒情（主段） |
| i–VII–VI–VII | Am–G–F–G | 循环压迫 |
| i–iv–VI–V | Am–Dm–F–E | 古典悲剧（climax 前） |
| i–III–VII–iv | Am–C–G–Dm | 明亮转暗 |
| VI–VII–i | F–G–Am | 电影式爬升 |
| i–VI–iv–V | Am–F–Dm–E | 最直白悲伤 |
| i–v–VI–IV | Am–Em–F–D | 下行叹息（ambient 首选） |
| III–VII–VI–V | C–G–F–E | 希望感 |
| i–VI–VII–III | Am–F–G–C | 悬而未决（outro） |

整曲只用 2 组，每 4 小节换一次即可。

## 3 旋律规则

- 2 小节一句、4 句一乐段（1/3 句同、2 句变尾、4 句收主音或三音）。
- 模进移位 2–3 次后必须打破。
- 级进 60–70%、三度 20%、跳进 ≤15%；≥四度跳进后下一音反向级进；不连续两个 ≥五度跳进；单次跳进 ≤八度。
- 高潮在 65%–75% 处，之后不再更高。
- 主段用附点/切分，Climax 用 2–4 拍长音，Outro 回落八分疏音。
- 避免同音反复 >3 次；避免长音落在弱拍和弦外音。

## 4 编曲分层与频段

Intro：pad + 稀疏钢琴（2 层）；A：+ sub + kick + 主旋律（4）；B：+ hihat/ride + 副旋律 + 弦乐（5–6）；Climax：+ 弦乐八度加倍 + clap + crash + 高频 shimmer（6–7）；Outro 逐层撤到 2 层。

五层频段：20–60 sub（单声道）/ 60–250 kick+bass 谐波 / 250–500 弦乐电钢与 pad（最易浑浊）/ 500–2k 旋律主体 / 6–16k hihat、bell、空气。

避让：kick 与 sub 在 60–100 Hz 二选一 + sidechain（衰减 3–6 dB，释放 80–120 ms）；pad 在 200–400 Hz 挖 −2…−3 dB；钢琴/电钢与 hihat 各自高通；低音与和弦层至少隔一个八度。

## 5 混音与母带（相对关系）

峰值参考：kick −6、snare −8、sub −8、bass −9、主旋律 −10、pad −14、hihat −18、混响返送 −20 dBFS；主旋律比伴奏高 2–3 dB。
总线压缩：阈值 −12 dB、2:1、起音 10–30 ms、释放 100–200 ms、衰减 1–3 dB。限幅天花板 −1.0 dBTP、衰减 ≤2 dB。
混响湿比 15–25%（主奏 20%、pad 35%），预延迟 20–40 ms，衰减 2–3.5 s。延迟同步 1/8 或附点 1/8，反馈 20–35%，混合 <15%。
声场：kick/sub/主旋律居中，pad ±70–100%，钢琴 ±30–50%，hihat ±40%，混响全宽，<120 Hz 强制单声道。

## 6 合成配方要点

暖 Pad：2–3 层锯齿 detune ±7–15 cent + 正弦 sub；低通 1.2–2.5 kHz；attack 0.8–2 s，release 2–4 s。
Pluck：锯齿+方波或 FM 1:3；低通包络 4 k→800 Hz / 120 ms，amp decay 150–300 ms，sustain 0。
电钢 FM：比 1:1，mod decay 400 ms，attack 3 ms / decay 1.2 s / sustain 0.3 / release 0.8 s。
Sub bass：纯正弦，attack 5–15 ms，release 120–200 ms，单声道，轻饱和加二次谐波。
弦乐：锯齿 ×2（+3–7 cent）+ 轻噪声，低通 2–3.5 kHz，attack 120–250 ms，揉弦。
Bell：FM 1:3.5 或 1:7，decay 1.5–3 s，混响 40%。
Kick：正弦 120→45 Hz（30–60 ms），amp decay 120–200 ms，5 ms 噪声 click，轻饱和。
Snare：200 Hz 正弦 decay 100 ms + 噪声带通 1.5–4 kHz decay 150–250 ms。
Hihat：噪声或 6 个失谐方波，高通 7–8 kHz，closed decay 30–60 ms / open 250–400 ms。
Clap：3–5 段噪声脉冲间隔 8–12 ms，带通 1–2 kHz，末段 decay 200 ms。

## 7 常见「业余感」错误

1. 所有层同进同出（应每 8 小节只增减一层）。
2. 只用根位置三和弦（≥30% 用转位/七音）。
3. 旋律音区与节奏一成不变。
4. 低频堆积（120 Hz 下单音化 + sidechain）。
5. 混响湿比 >40% 导致无层次。
6. 整曲 RMS 波动 <3 dB。
7. 靠推满音量代替编曲（限幅衰减 >3 dB 就该回退重配）。
8. 完全量化僵硬（旋律/钢琴需 ±10–20 ms 人性化，pad 不动）。
9. 8 小节以上不变化和弦。
10. 结尾突兀（Outro 逐层撤 + 2–3 s 混响尾）。
