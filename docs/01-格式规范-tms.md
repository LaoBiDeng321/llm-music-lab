# 01 TMS 文本乐谱格式规范 v1

TMS = Text Music Score。目标：让**人和 LLM 都能直接读写**，不需要任何专用编辑器；语义显式、可 diff、可增量修改。

## 1. 文件与词法

- UTF-8 纯文本，扩展名 `.tms`，一个文件一首曲子。
- 行导向：一行一条指令或一个事件。空行忽略，缩进不参与语义（建议 pattern 内缩进 4 空格）。
- 注释：`#` 起至行尾。`#` 出现在行首或空白之后才算注释（避免吃掉 `C#5`）。
- 标识符（track 名、pattern 名）：`[A-Za-z_][A-Za-z0-9_]*`。
- 数字：整数或小数；速度、时刻一律以**拍（beat）**为单位，不用毫秒。

## 2. 全局指令（文件顶层，顺序无关）

| 指令 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `tempo <bpm>` | 20..300 | 120 | 全曲恒定速度 |
| `meter 4/4` | 仅 4/4 | 4/4 | v1 只支持 4/4，其他值报错 |
| `key <调>` | 如 `Am`、`C`、`Dm` | 无 | 只供校验器判断调外音，不影响渲染 |
| `swing <比例>` | 0..0.4 | 0 | 每个 16 分网格中第 2 个八分音符（格位 2、6、10、14）后移 `比例×0.25` 拍 |
| `humanize <秒>` | 0..0.05 | 0 | 事件起点随机抖动幅度（±值），力度抖动为 ±10% |
| `seed <整数>` | 任意 | 0 | humanize 随机种子，保证可复现 |
| `section <名称> bars <a>-<b>` | — | — | **纯信息**，供可视化/分析画段落；不参与渲染 |
| `instrument <名称> <k=v>...` | 见 §3 | — | 声明一个声部 |
| `pattern <track>.<名称> { ... }` | 见 §4 | — | 声明一个乐句单元 |

## 3. `instrument` 参数

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `patch` | 见 `02-音色与混音.md` | **必填** | 音色 |
| `gain` | 0..2 | 1 | 线性增益 |
| `pan` | -1..1 | 0 | -1 全左，1 全右 |
| `reverb` | 0..1 | 0 | 混响送出量 |
| `delay` | 0..1 | 0 | 八分延迟送出量 |
| `chord` | `hold`/`arp-up`/`arp-down`/`arp-updown`/`arp-up8`/`stab`/`root`/`root8` | `hold` | 和弦记号如何展开成音 |
| `subdiv` | >0（拍） | 0.5 | `arp-*`/`stab`/`root8` 的步长 |
| `octave` | 整数 | 0 | 整体移调八度；和弦默认落在第 3 八度（根音 MIDI 48..59），此参数在此基线上叠加 |
| `accent` | 逗号分隔的 0..1 列表 | 全 1 | 循环施加在 `arp-*`/`stab`/`root8` 每一步上的力度倍率，如 `accent=1,.55,.75,.6` |
| `chorus` | 0..1 | 0 | 合唱/加宽送出量 |
| `duck` | 声部名或 `kick` | 无 | 侧链：该声部在 `kick`（或指定声部）击发时衰减 4.5 dB |
| `humanize` | 秒 | 全局值 | 覆盖全局 humanize |

和弦展开规则（`voicing` = 该和弦在第 3 八度上的原位音，升序排列）：

- `hold`：和弦音同时发声，时值 = 事件时值。
- `arp-up`：按 `subdiv` 依次弹和弦音，循环回根音（不叠八度）。
- `arp-up8`：同上，但每循环一次整体升 8 度（共跨 2 个八度）。
- `arp-down`：降序循环。
- `arp-updown`：升到顶再降回（乒乓）。
- `stab`：每个 `subdiv` 同时弹全部和弦音，时值 = `0.45×subdiv`。
- `root`：只弹和弦根音，时值 = 事件时值（贝斯长音用）。
- `root8`：按 `subdiv` 弹根音脉冲，每 4 步把最后一步换成五度（贝斯律动用）。

## 4. `pattern` 块

```
pattern keys.arpA {
    # 事件行：<音高> <起始拍> <时值> [力度]
    E5 0 1.5 .92
    Am 0 4            # 和弦记号，起始 0 拍，长 4 拍

    # 网格行：先声明密度，再逐声部写符号
    grid 16
    kick  X . . . . . X . . . X . . . . .
    snare . . . . X . . . . . . . X . . .
}
```

- **音高记号**（三选一，解析顺序：鼓件名 → 音名 → 和弦符号）
  - 音名：`C4` `A#3` `Bb5`（科学音高记号，C4 = MIDI 60）。**八度必须 ≤ 6**。
  - 和弦：`Am` `Fmaj7` `Cadd9` `G/B` `Esus4` `Dm7` `Bbmaj7` `E7`
  - 鼓件：`kick` `snare` `hat` `ohat` `clap` `ride` `crash` `rim` `tom` `shaker` `riser` `downlift`

  > **歧义消解**：`E7` 这类记号同时像「第 7 八度的 E 音」和「E 属七和弦」。约定八度 ≥ 7 一律按和弦解析，
  > 因此第 7 八度以上的音无法用音名书写（实际也不需要）；`A5`/`C5` 这类「字母+数字」一律是音名，
  > 所以和弦表不提供强力和弦 `5`。六和弦请写 `Xadd6`。
- **起始拍**：相对 pattern 起点，可跨小节；范围 0 ≤ start < 32。
- **时值**：> 0，单位拍。
- **力度**：0..1，省略为 0.8。
- **网格行**：`grid <每小节格数>` 后跟若干 `<声部> <符号串>`。
  - 每格时值 = 每小节拍数 / 格数（16 格 → 0.25 拍）。
  - 符号：`X` 力度 1.0；`x` 0.8；`o` 0.7；`.` 与 `-` 为休止。空格可省略。
  - **同一声部再次出现即推进到下一个小节**：同一 `grid` 段内第 n 次出现 `kick` 行 = 第 n 小节。
  - 符号数必须等于格数，否则报错。

## 5. `arrange` 块

```
arrange
    bars 1-8              pad.intro, keys.padA
    bars 9-16|33-40       bass.pulseA, drum.groove
    bars 17-20            lead.themeA transpose=+12 gain=0.9 pan=-0.2
```

- 行格式：`bars <范围>[|<范围>...] <条目>[, <条目>...]`
- 范围：`<起>-<止>`（含两端，小节号从 1 开始）；用 `|` 可把同一组内容放到多处。
- 条目：`<track>.<pattern>`，`<track>` 必须是已声明的 `instrument`。
- 修饰（可选，可多个）：`transpose=<半音数>`、`gain=<倍数>`、`pan=<-1..1>`、`octave=<整数>`。`gain` 与 instrument 行的 `gain` 相乘。
- **放置语义**：pattern **从范围起始小节开始，循环重复直到填满范围**。
- **循环长度**（重要）：= 最后一个事件的「起拍 + 时值」，**向上取整到整小节**。
  - 1 小节的鼓 pattern 放进 `bars 9-16` → 连打 8 遍。
  - 8 小节的 Pad pattern 放进 `bars 9-16` → 正好一遍。
  - 取整这一步是必须的：鼓网格若最后一格是休止（例如 `hat` 只写到第 14 格），原始长度会是 3.75 拍而不是 4 拍；不取整的话循环会每小节漂 0.25 拍，整段鼓点逐步错位。
  - pattern 比范围长时只播一遍并越过范围末尾；范围长度不是循环长度的整数倍时最后一遍会被截断 —— 这两种情况校验器都会给警告。

## 6. 长度与时间

- 每小节 = 4 拍（v1 固定）。
- 第 n 小节第 b 拍（0 ≤ b < 4）的绝对拍位置 = `(n-1)*4 + b`。
- 秒 = 拍 × 60 / tempo。
- 全曲长度 = arrange 覆盖到的最末小节 + 混响尾巴（由渲染器补）。

## 7. 校验规则（`python -m tmskit check`）

**错误（阻断渲染）**
1. 未知指令 / 参数名 / 无法解析的取值。
2. `patch` 未在音色表中登记。
3. `arrange` 引用了未定义的 `pattern`。
4. pattern 的 track 没有对应 `instrument`。
5. 小节范围越界、起 > 止、范围未声明。
6. 音高/和弦/鼓件记号无法解析；符号数与网格格数不符。
7. 时值 ≤ 0、起始拍越界、力度越界。
8. `arrange` 完全为空。

**警告（不阻断）**
1. 调外音（`key` 已声明时）；小调允许升七级（导音），不报。
2. 强拍（每小节第 0 拍）落在非和弦音上（只检查显式音名事件，和弦记号事件除外）。
3. 同一 track 在同一小节被两条 arrange 条目叠加（会变成两层声音）：有意的叠加请写在同一个 pattern 里，或把范围错开。
4. 音符超出该 patch 的推荐音域。
5. pattern 的循环长度超过所在地范围长度，或范围长度不是其整数倍。
6. 同一 pattern 内同一音高、同一时刻、同一力度完全重叠。
7. 展开后存在没有任何事件的小节（编曲空洞提示）。
