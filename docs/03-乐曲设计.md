# 03 本曲设计：《潮汐尽头》

`score/tide-end.tms` 的创作说明。写给后续要改这首曲子的人/agent：**改之前先读这里**，否则很容易破坏动机与和声的对应关系。

## 1 基本参数

| 项 | 值 |
|---|---|
| 调性 | A 自然小调；E7 处用升七级 G# 作导音（和声小调混用） |
| 速度 / 拍号 | 92 BPM · 4/4 |
| 长度 | 72 小节 = 187.8 秒 + 混响尾 ≈ 3:12 |
| 声部数 | 15 |
| 事件数 | 2720 次发声 |
| 最高音 | C6，仅出现在第 53 小节第 2 拍（全曲 72% 处） |
| 交付母带 | 整体 RMS −16.3 dBFS、真峰值 −1.0 dBTP、削波 0、声道相关度 +0.60、限幅衰减 2.0 dB、两次渲染逐字节一致 |

## 2 段落与动态弧

| 段落 | 小节 | 层数 | 新增元素 | 实测 RMS |
|---|---|---|---|---|
| 序 | 1-8 | 2→3 | Pad、钟琴、稀疏电钢；第 7 小节长音贝斯进 | −21.3 |
| A1 | 9-16 | 5 | 主旋律第一遍、八分电钢、root8 贝斯、轻鼓 | −17.1 |
| A2 | 17-24 | 6 | 加弦乐、高八度拨弦琶音；句尾转 Dm–E7 | −16.5 |
| B1 | 25-32 | 7 | 副歌主题、人声 Pad、十六分尼龙琶音、对位、完整鼓组 | −16.6 |
| B2 | 33-40 | 7 | 加柱式电钢、开镲；末句长音 | −16.5 |
| 桥 | 41-48 | 3 | 抽掉鼓与贝斯律动，只留 Pad 与电钢分解；第 47-48 小节渐强 + riser | −18.9 |
| 高潮 | 49-64 | 8 | 全奏：主题再现 + 对位 + 弦乐 + 空气层 + 十六分琶音 + 全鼓组 | −15.7 |
| 尾声 | 65-72 | 6→2 | 逐层撤退，最后只剩 Pad 长音 + 钟琴 + Sub 长音 | −19.2 |

动态弧为单峰（极差 5.6 dB）：序 → A → B → 桥（谷底）→ 高潮（峰，段落内部还在上行）→ 尾声。
段间落差由 `python -m tmskit analyze` 的段落 RMS 表核对。

> 鼓组的「fill 小节」不要和基础 groove 放在同一小节：同一声部在同一小节被两条条目覆盖会叠成两层。
> 本曲的写法是把基础 groove 的范围让开 fill 那一小节（如 `bars 9-15 drum.soft` + `bars 16-16 drum.fill`），
> 校验器会对任何同轨同小节的叠加报警。详见 [06](06-关键决策与踩坑记录.md) B10。

## 3 和声进行

```
verse   Am F C G | Am F C G         i-VI-III-VII   抒情基调（序 / A1 / 高潮前半）
verse2  Am F C G | Am F Dm E7       i-VI-iv-V      句尾推动到副歌
chorus  F C G Am | F C G G          VI-I-V-i       明亮上行（B1）
chorus2 F C G Am | F Dm E7 E7       VI-I-iv-V-V    收在属和弦（B2 / 高潮后半）
bridge  Am F Dm E7 | Am F Dm E7     i-VI-iv-V       最直白的哀伤循环（桥）
outro   Am F C G | Am F C Am        回到主调
```

整曲只用两组进行（verse 族与 chorus 族）加一个桥段循环，靠织体而非和弦数量制造张力。
七和弦与转位使用率 > 30%（E7、Dm7 语境、`G/B` 等）。

## 4 动机与主题

动机 **M**（`lead.M`，2 小节一句、4 小节一乐段）：

```
第1小节(Am) E5-A5-G5-E5   第2小节(F) F5-E5-D5
第3小节(C)  E5-G5-A5-G5   第4小节(G) D5-B4
```

- 轮廓为拱形，乐句顶点 A5 落在第 3 小节第 3 拍。
- 级进为主（约 65%），跳进集中在 E5→A5（四度）与 G5→E5（三度），跳进后一律反向级进。
- 长音落在强拍且是当时和弦的根/三/五音（校验器逐小节检查）。

发展手段（每次只改一项）：

| 段落 | 手法 |
|---|---|
| A1 | 原型陈述两遍 |
| A2 | 换尾：末句 G# 导音拉回主调（`lead.M2`） |
| B1 | 音区抬高（A5–B5）、时值放长，情绪展开（`lead.C`） |
| B2 | 加花上行 + 长音收束（`lead.C2`） |
| 桥 | 逆行/稀释：原型的碎片、每 2 小节一句（`lead.bridgeA/B`） |
| 高潮 | 变形：动机移位到 C6 形成全曲唯一最高点（`lead.M3`），随后副歌主题再现 |
| 尾声 | 原型碎片 + 收在主音 A5（`lead.outro`） |

## 5 配器分层与频段分配

| 层 | 声部 | 频段 |
|---|---|---|
| 低频 | `bass`/`bass2`（sub-bass，120 Hz 以下单声道 + 侧链让位给 kick） | 40–120 Hz |
| 节奏底 | `drum` / `fx` | kick 60–250 Hz，snare/clap 0.9–5 kHz，hat/ride 5–16 kHz |
| 和声床 | `pad`、`choir`、`strings`、`shimmer` | Pad 130–500 Hz，弦乐 300 Hz–2 kHz，空气层 6–16 kHz |
| 织体 | `keys`（八分分解）、`epi`（柱式）、`arp`（十六分）、`arp2`（高八度八分） | 250 Hz–6 kHz |
| 主奏 | `lead`（拨弦）、`counter`（对位） | 500 Hz–2 kHz（人耳最敏感区） |

避让规则（已在乐谱/工具链中落实）：

1. 同一时刻只有一条最快节奏线：序无快速线 → A 段八分 → B 段十六分 → 桥停下 → 高潮十六条 + 十五分钟。
2. Pad 与 Sub 均挂 `duck=kick` 侧链；120 Hz 以下母带强制单声道。
3. Pad/弦乐通通避开 2–4 kHz；`counter` 与 `lead` 成三/六度关系而非同度叠。
4. 每 8 小节至少增减一层；段落交界留空（桥段第 47 小节只有 shaker 与 kick）。

## 6 修改指引

- 改任何旋律音后跑 `python -m tmskit check score/tide-end.tms`，确认「强拍和弦音」警告为 0。
- 改和声进行时，必须同步改所有引用该进行的 pattern（`pad.*`、`keys.*`、`arp.*`、`bass.*`、`strings.*`、`shimmer.*` 各有一套同名的 8 小节版本）。
- pattern 长度即循环长度：4 小节 pattern 放进 4 小节范围播一遍，放进 8 小节范围播两遍。改动 pattern 末音的时值会改变它的循环次数与对齐，必须复核。
- 想换音色只改 `instrument` 行的 `patch=`，不要改乐谱里的音高（音色的推荐音域见 `docs/02`）。
