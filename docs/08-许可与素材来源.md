# 08 许可与素材来源

## 1 双协议

本项目**代码与作品分开授权**：

| 范围 | 内容 | 协议 |
|---|---|---|
| 代码与文档 | `tmskit/**`、`docs/**`、`README.md`、`AGENTS.md`、`tests/**` | **MIT**（见 [../LICENSE](../LICENSE)） |
| 音乐作品 | `score/**`（乐谱）、`out/*.wav`、`out/*.flac`、`out/*.png` | **CC BY 4.0**（见 [../LICENSE-MUSIC](../LICENSE-MUSIC)） |

一句话：**代码随便用（保留版权声明即可），音乐随便用（署名即可，商用也可以）。**

想改成更宽松或更严格的协议，只需替换这两个文件，并同步更新本节与 README —— 没有别处引用协议内容。

## 2 素材来源：全部自产，零外部素材

| 内容 | 来源 | 说明 |
|---|---|---|
| 全部音色 | `tmskit/voices.py`、`tmskit/drums.py` 实时合成 | **没有任何采样**：鼓、Pad、钢琴、弦乐都是正弦/噪声 + 包络 + 滤波算出来的 |
| 混响 | `effects.make_impulse_response()` 程序生成 | 用衰减噪声合成 IR，不是真实空间录音 |
| 乐谱 | `score/tide-end.tms` | 为本次创作从零写的 |
| 钢琴卷帘图 | `visualize.py` 用 Pillow 画 | 图中的中文用系统字体渲染成像素，不含字体文件 |
| 文档配图/文字 | 本项目自写 | — |

因此，**音频与乐谱不牵连任何第三方权利**，你可以自由分发。

## 4 关于「AI 生成」的版权提示

这份作品与代码是在人类用户的需求、方向选择与验收下，由 AI 编码代理在用户本机产出的。需要如实说明两点：

1. **部分司法辖区（如美国版权局现行实践）要求作品具备「人类作者」才受版权保护**。因此上述 MIT / CC BY 授权可以照常声明和发布，但在这些辖区，**维权能力可能受限**。这不影响别人合法使用，也不影响你分发。
2. **无法保证与现有作品无相似之处**：和弦进行、常见音型属于公共领域的音乐语法，但整体相似性本项目没有做过检索与比对。若用于商业发行，建议自行做一次相似度核查。

如果你打算正式发布，建议在作者栏署名你自己（提出需求、确定方向、最终验收的人），这是同类项目的常见做法。
