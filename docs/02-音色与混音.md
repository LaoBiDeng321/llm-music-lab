# 02 音色与混音

工具链内置音色表。**新增 patch 必须在本文件登记**（`AGENTS.md` §6.2）。
音色参数属工具链（`tmskit/voices.py`、`tmskit/drums.py`），乐谱只能通过 `instrument` 行选择 patch 并调整增益/声场/送出量，不得写死波形参数。

## 1 有音高音色（`voices.py`）

归一化约定：

- `norm=rms`：按「有效 RMS」（40 ms 滑动 RMS 的 88 分位）归一化到 `nominal_db`。适合有稳定延音的铺底类。
- `norm=peak`：按峰值归一化到 `nominal_db`。适合一次性击发类（拨弦、电钢、钟琴）。
- 力度响应 `amplitude = vel^1.5`，另加音色自身的力度→亮度响应。
- 峰值兜底 0.9（−0.9 dBFS），任何单次触发都不会削波。

| patch | 类型 | 推荐音域 | 归一 | 合成配方 | 包络 |
|---|---|---|---|---|---|
| `saw-pad` | pad | C2–E5 | rms −24 | 锯齿 26 次分音 × 3 层失谐（±9 cent） | A 0.85s / D 1.6s / S 0.82 / R 2.6s；截止 900→2500 Hz |
| `glass-pad` | pad | E2–E6 | rms −25 | 三角族（奇次 1/k^1.7）× 3 层（±12 cent） | A 1.1s / S 0.85 / R 3.0s；截止 1.4k→4.2k；揉弦 0.22 Hz |
| `choir-pad` | pad | C2–C6 | rms −24.5 | 锯齿 × 3 层（±7 cent），人声共振峰加权 | A 1.3s / S 0.9 / R 2.8s；揉弦 4.6 Hz |
| `epiano` | 键盘 | C2–C7 | peak −12 | FM 1:1，调制指数 3.4→0.5（τ=0.34s）+ 失谐 4 cent 副层 + 9 倍频 tine 瞬态 | A 4ms / D 1.15s / S 0.30 / R 0.9s |
| `bell` | 钟琴 | C3–G7 | peak −16 | FM 1:3.5，指数 2.6（τ=0.9s）+ 2 倍频点缀 | A 2ms，衰减 τ=1.5s |
| `music-box` | 八音盒 | C4–A7 | peak −18 | FM 1:7，指数 1.9（τ=0.35s） | A 2ms，衰减 τ=0.85s |
| `pluck` | 拨弦 | E2–E7 | peak −10 | 锯齿 24 次分音 × 2 层（±4 cent） | A 4ms，衰减 τ=0.32s，上限 1.5s；截止 4.2k→700（τ=0.11s） |
| `lead-hybrid` | 主奏 | E2–D7 | rms −23 | 延音主体（锯齿 × 2 层 ±5 cent）+ 拨弦起音层，两层 0.78/0.52 相加 | 主体 A 35ms / D 0.55s / S 0.74 / R 0.55s；起音层 τ=0.26s |
| `nylon` | 拨弦 | E2–G#6 | peak −12 | 1/k^1.6 谱型 | A 6ms，衰减 τ=0.55s，上限 2.0s；截止 2.6k→500 |
| `sub-bass` | 贝斯 | C1–C4 | rms −14 | 正弦 + 半频 Sub 层 + 2/3/4 次谐波（0.50/0.16/0.06/0.02），轻饱和感 | A 12ms / D 0.12s / S 0.92 / R 0.18s |
| `strings` | 弦乐 | E2–C7 | rms −24 | 锯齿 22 次分音 × 2 层（±6 cent） | A 0.22s / S 0.88 / R 1.0s；揉弦 5.2 Hz |
| `swell-strings` | 弦乐 | C2–C7 | rms −25 | 同 strings，长起音 | A 1.1s / S 0.95 / R 1.6s |
| `shimmer` | 空气层 | C4–C8 | rms −32 | 三角族 × 4 层（±14/27 cent），整体升八度 | A 1.6s / S 0.9 / R 3.4s |

**加法合成实现**：所有分音在时域用 2 极点低通响应 `fc²/(fc²+f²)` 整形，`fc` 随时间按指数曲线滑动 → 无需 IIR 循环即可得到随时间变化的音色亮度，且天然无混叠。

## 2 打击乐（`drums.py`，patch = `drumkit`）

峰值电平 @ vel=1（相对配比比绝对值重要，母带统一抬到目标响度）：

| 鼓件 | 峰值 | 配方 |
|---|---|---|
| `kick` | −12 | 正弦音高 140→45 Hz（τ=30ms）+ 1.4k 高通噪声 click（3.5ms）+ tanh 饱和，衰减 τ=0.155s |
| `snare` | −13 | 196/286 Hz 正弦（τ=48/32ms）+ 1.25–5.6k 带通噪声（τ=115ms） |

| `ride` | −18 | 6 个非谐金属分音（1/1.47/1.93/2.51/3.17/3.83×340Hz）+ 5.2k 高通噪声 |

## 3 效果与总线的固定参数（`effects.py` / `render.py`）

| 环节 | 参数 | 说明 |
|---|---|---|
| 混响 | 合成 IR：4 频段不同衰减（低 1.15×、中 1.0×、1.2–4.5k 0.62×、高 0.32×），decay 2.8s，预延迟 32ms，9 条早反射；两声道做 0.55 倍部分相关（保证单声道兼容） | 送出量由乐谱 `reverb=` 决定；返回电平 0.55，180 Hz 高通 |
| 延迟 | 八分音符（`0.75 × 拍`），反馈 0.32，乒乓左右交替，320 Hz–5.2 kHz 带通 | 送出量由乐谱 `delay=` 决定 |
| 合唱 | 0.28 Hz、深度 8ms、2 声部 | 由乐谱 `chorus=` 控制 |
| 侧链 | `duck=kick`：键控内部 kick 总线，衰减 −4.5 dB，起音 8ms，释放 110ms | 让 sub 与 pad 给底鼓让位 |
| 母带 EQ | 28 Hz 四阶高通、+2.0 dB @58 Hz、+1.8 dB @160 Hz、−2.2 dB @350 Hz、+1.0 dB @2.4k、+2.8 dB @10.5k | 补 Sub、加温暖、去浑浊、提存在感与空气感 |
| 胶水压缩 | 阈值 −11 dB、1.6:1、起音 25ms、释放 180ms | 段落间更连贯（衰减约 1 dB） |
| 归一 | 整体 RMS → −14.5 dBFS（限幅后实测约 −16.5） | 交付门禁 −18..−12 |
| 限幅 | 前视 6ms、释放 90ms、天花板 −1.0 dBFS | 硬性最后一级；本曲实测衰减 2.1 dB |
| 真峰值 | 4 倍过采样估计，> −1.0 dBTP 时整体回退 | 保证不超真峰值上限 |
| 低频单声道 | 120 Hz 以下强制单声道 | 避免低频相位抵消 |
| 声场 | 立体声宽度 1.08 | — |
| 输出 | 44100 Hz / 16-bit PCM / 立体声 WAV，写盘加 TPDF 抖动 | 定死 |
